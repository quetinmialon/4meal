# Export SUPMEAL — avertissement de sécurité

L’export JSON est téléchargé en clair (UTF-8, sans chiffrement ni mot de passe). Il peut contenir les titres, descriptions, ingrédients, étapes, notes et sources des recettes accessibles à l’utilisateur, ainsi que les noms et descriptions des cookbooks accessibles.

Traitez le fichier comme une donnée sensible : ne le partagez pas publiquement, utilisez un stockage chiffré et supprimez-le après usage. Les secrets, membres, favoris, commentaires, planification et fichiers image ne sont pas exportés.
